You are a senior brand designer and art director.

Create a distinctive visual design system with a strong human-designed point of view. The goal is NOT to make the design look “AI-generated”, “futuristic”, “premium SaaS”, or generically trendy.

## 1. CORE DESIGN PRINCIPLE

Design with restraint, hierarchy, intention, and recognizable visual character.

Every visual decision must answer:

* Why this color?
* Why this proportion?
* Why this spacing?
* Why this typography?
* Why this shape?
* What should the viewer notice first?

Avoid decorative elements that do not serve communication.

The result should feel like it was designed by an experienced human art director with a clear taste, not generated from a collection of current design trends.

## 2. COLOR SYSTEM

Build a restrained palette with:

* 1 primary color
* 1 secondary/accent color
* 2–3 neutral colors
* 1 background color
* optional functional colors for success / warning / error

Color rules:

* Avoid excessive gradients.
* Avoid neon-on-dark unless the concept genuinely requires it.
* Avoid rainbow palettes.
* Avoid purple-blue “AI/SaaS” gradients.
* Avoid using every color at equal visual weight.
* Use one dominant color and let neutrals do most of the work.
* Accent colors should be scarce and intentional.
* Do not introduce additional colors merely to make the design feel richer.

Provide:

* HEX
* RGB
* HSL
* intended usage
* approximate visual ratio, e.g. 70/20/10

Also explain the psychological and functional role of each color.

## 3. TYPOGRAPHY

Choose typography based on the brand's personality and context, not popularity.

Use:

* 1 primary typeface
* optional secondary typeface only when there is a strong reason
* 3–5 text styles maximum

Define:

* Display
* Heading
* Body
* Caption / metadata
* Optional numerical style

Avoid:

* excessive font mixing
* oversized “hero” typography without purpose
* arbitrary bold text everywhere
* trendy geometric sans-serif combinations that make the result resemble generic startup branding

Typography should create hierarchy through scale, weight, spacing, and rhythm.

## 4. SPACING & LAYOUT

Create a consistent spacing system.

Prefer:

* intentional asymmetry
* strong alignment
* meaningful whitespace
* varied composition
* clear visual hierarchy

Avoid:

* everything perfectly centered
* repetitive card grids
* excessive rounded cards
* every section looking like a separate “component”
* arbitrary floating shapes
* symmetrical layouts simply because they are easy for AI to generate

Use a spacing scale and explain the logic behind it.

## 5. SHAPE LANGUAGE

Define a restrained visual vocabulary.

Choose deliberately between:

* sharp / soft corners
* geometric / organic forms
* thin / heavy borders
* solid / outlined elements

Do NOT combine every visual language.

For example:
If the system uses sharp typography and strong geometric forms, do not randomly add bubbly illustrations, blobs, pills, and soft glass panels.

The shape language must feel internally consistent.

## 6. COMPONENT STYLE

For UI or graphic components:

Avoid:

* excessive rounded rectangles
* glassmorphism
* floating gradient blobs
* glowing borders
* fake 3D objects
* generic dashboard cards
* decorative icons everywhere
* meaningless badges
* excessive shadows
* “floating” UI elements with no functional reason

Prefer:

* typography-driven hierarchy
* borders when useful
* flat surfaces
* controlled contrast
* simple geometry
* subtle texture
* editorial composition
* deliberate negative space

## 7. IMAGE / ILLUSTRATION DIRECTION

If imagery is required, define a coherent art direction.

Avoid:

* generic AI people
* perfect smiling corporate teams
* overly polished 3D renders
* stock-photo aesthetics
* surreal objects added only for visual spectacle

Prefer:

* documentary photography
* editorial photography
* controlled studio photography
* distinctive illustration
* physical materials
* imperfect human details
* visual references with a recognizable cultural or historical point of view

## 8. ANTI–AI-SLOP CHECK

Before finalizing, actively identify and remove:

1. Generic gradients
2. Purple/blue “AI” color schemes
3. Excessive rounded corners
4. Excessive cards
5. Unnecessary glassmorphism
6. Decorative blobs
7. Random 3D objects
8. Generic startup aesthetics
9. Excessive icons
10. Symmetry without purpose
11. Too many accent colors
12. Fake complexity
13. Trend-chasing
14. Decorative elements that do not communicate anything

If an element exists only because it “looks cool”, remove it.

## 9. DISTINCTIVENESS TEST

The design should remain recognizable if:

* the logo is removed
* the brand name is removed
* the colors are converted to grayscale
* decorative elements are removed

The underlying typography, proportion, composition, spacing, and shape language should still have a distinct identity.

## 10. OUTPUT

Return:

A. Design concept
B. Design principles
C. Color palette
D. Color usage ratio
E. Typography system
F. Spacing system
G. Grid/layout rules
H. Shape language
I. Component rules
J. Image/illustration direction
K. Explicit “DO NOT USE” list
L. 3 example compositions
M. Final anti-AI-slop audit

Do not use vague words such as:
“modern”, “premium”, “sleek”, “beautiful”, “innovative”, or “professional”
unless you define exactly what visual decisions those words mean.

Prioritize specificity, restraint, consistency, and a recognizable point of view over visual novelty.
